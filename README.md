# 油品价格维护 · 含税倒推与税务复核台

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务规则

调价单填写站点、油品、含税售价、税率和生效日，系统自动倒推金额并做税务复核：

1. **必填完整（R1）**：站点、油品、含税售价、税率、生效日缺一不可。
2. **按分计价（R2）**：含税售价为正数且最多两位小数。
3. **税率合法（R3）**：13% / 9% / 6% / 3%，13% 为成品油标准税率。
4. **同键唯一（R4）**：同站同油品同生效日只能一条；变更只能对原单"更正"。
5. **金额恒等（R5）**：不含税价 = 含税价 ÷ (1+税率) 按分四舍五入；税额按倒推法
   （含税价 − 不含税价）取值，保证 `含税价 = 不含税价 + 税额`（分）恒等。
   另以正算税额交叉校验，**差额超过一分不得发布**。
6. **异常依据（R6）**：差额一分或非标准税率属异常，必须财务写依据。
7. **财务复核（R7）**：异常单须财务复核并留痕（复核人、意见）。
8. **发布冻结（R8）**：复核通过后冻结税率、金额、依据；更正另立版本，旧值留档。

## 分层结构

- `src/rules/`：规则层。纯函数（税务倒推、规则表、校验），不依赖 Vue 与存储。
- `src/store/repository.ts` + `types.ts` + `seed.ts`：存储层。localStorage
  持久化（`dfwlfront-9-tax-review-v1`），受阻记录在 sessionStorage，刷新后不丢。
- `src/store/priceStore.ts`：状态层（Pinia），编排规则与存储，处理冻结与版本链。
- `src/components/`、`src/App.vue`：展示层，只读引用规则层常量与提示文案。

受阻操作统一在"税务复核受阻台"显示**站点、油品、生效日、税额差额（分）与命中规则**。
