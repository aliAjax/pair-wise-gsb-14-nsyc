# 油品含税倒推与税务复核台

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia（localStorage 持久化）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

在"油品价格维护"基础上扩展为**含税倒推 + 税务复核台**，数据保存在浏览器 localStorage 中。

## 业务规则

1. 调价单填写：站点、油品、含税售价、税率、生效日。
2. 倒推：不含税价 = 含税价 ÷ (1 + 税率)；税额 = 含税价 − 不含税价；三项金额一律**按分四舍五入**。
3. 勾稽：含税价 = 不含税价 + 税额必须相等（差额 0）；
   - 差额恰为 ±1 分：税额异常，可提交复核，但**必须由财务填写计税依据并复核**；
   - 差额超过 1 分：**不得发布**，表单直接受阻。
4. 同站、同油品、同生效日只能有一条有效调价单（更正沿用同一单号升版本，不另占唯一键）。
5. 复核通过后**冻结税率、金额、计税依据、复核人**；更正只能另立新版本，旧版本原样保留并标记"已更正"。
6. 受阻提示统一显示：站点、油品、差额（分）与命中规则编号/名称。

## 分层结构

- `src/domain/`：规则层（纯函数/纯类型，不依赖 Vue 与存储）
  - `money.ts` 分整数金额、四舍五入与展示
  - `tax.ts` 含税倒推、差额分级、拆分复核
  - `rules.ts` 规则台账（R-REQUIRED / R-BALANCE / R-UNIQUE / R-BASIS / R-FROZEN）、草稿与发布校验
  - `types.ts` 领域模型
- `src/storage/priceStore.ts`：存储层，localStorage 读写、种子数据、刷新后一致性核对（金额拆分与版本链）
- `src/store/usePriceStore.ts`：Pinia 编排层，连接规则与存储
- `src/components/`：展示层（调价单、复核台、台账、受阻提示）
